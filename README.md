# 💼 Adult Income Salary Prediction — ML Web App

A complete end-to-end Machine Learning web application that predicts whether
an individual's annual income is **>50K** or **≤50K** based on census features.

Built with **Python**, **scikit-learn**, **pandas**, and **Streamlit**.

---

## 🗂️ Project Structure

```
salaryprediction/
├── app.py                  # Streamlit web application
├── train_model.py          # Data preprocessing, model training & saving
├── requirements.txt        # Python dependencies
├── README.md               # This file
├── agent_instructions.md   # Developer notes
├── .env.example            # Environment variable template
├── data/
│   └── adult.csv           # UCI Adult Census Income dataset (48,842 rows)
└── models/
    └── model.pkl           # Saved sklearn Pipeline (generated by train_model.py)
```

## 🚀 Quick Start (Local)

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/salaryprediction.git
cd salaryprediction
```

### 2. Create and activate a virtual environment
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model
```bash
python train_model.py
```

This will:
- Load `data/adult.csv`
- Preprocess the data (imputation, encoding, scaling)
- Compare Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting via 5-fold cross-validation
- Save the best-performing pipeline to `models/model.pkl`

### 5. Run the Streamlit app
```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501**

## 📊 Dataset

| Property | Value |
|---|---|
| Source | [UCI Adult Census Income](https://archive.ics.uci.edu/ml/datasets/adult) |
| File | `data/adult.csv` |
| Rows | 48,842 |
| Features | 14 (after dropping `fnlwgt`) |
| Target | `income` — `<=50K` (0) or `>50K` (1) |
| Problem Type | Binary Classification |

---

## 🤖 ML Pipeline

| Step | Detail |
|---|---|
| Missing values | `?` → NaN, imputed with median (numeric) / most-frequent (categorical) |
| Encoding | OneHotEncoder for categorical features |
| Scaling | StandardScaler for numeric features |
| Models compared | Logistic Regression, Decision Tree, Random Forest, Gradient Boosting |
| Selection criterion | 5-fold cross-validation F1-score |
| Serialisation | `joblib` — saves pipeline + metadata to `models/model.pkl` |

## ☁️ Deploy to Streamlit Community Cloud

1. Push your repository to GitHub (make sure `models/model.pkl` is committed, or add a training step).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch (`main`), and set **Main file path** to `app.py`.
4. Click **Deploy**. Streamlit Cloud will install `requirements.txt` automatically.

> **Note:** If you exclude `model.pkl` from git (e.g. via `.gitignore`), add a build
> step or a `@st.cache_resource` function that calls `train_model.py` on first run.
